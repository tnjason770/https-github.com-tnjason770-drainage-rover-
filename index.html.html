Section 02 • Mechanical, Electrical & Communication Design

02. Total Structural Architecture of the Rover & Remote

The system is engineered as two tightly integrated wireless units: the Amphibious Rover Unit (deployed inside the drainage line) and the Suitcase Command Controller (held safely above ground by the operator).

+-----------------------------------------------------------------------------------+ | UNIT A: AMPHIBIOUS DRAINAGE ROVER (SUB-SURFACE) | | | | [3S 18650 Battery Pack] ---> [LM2596 5V Buck Converter] ---> [30-Pin ESP32 #1] | | | | | | | | +---> [L298N Driver #1] ---> Front/Rear Left 60RPM Motors | | | | +---> [L298N Driver #2] ---> Front/Rear Right 60RPM Motors | | | | | | | | | [MQ-4 Methane Sensor] -----(Analog GPIO 34)----------------------+ | | | | [MQ-135 Toxic Gas Sensor] -(Analog GPIO 35)--------------------------+ | | | [IR Obstacle/Water Sensor]-(Digital GPIO 32)-----------------------------+ | | | | [TECHNOVIEW 1080p Wi-Fi IP Camera] ===(Independent 2.4GHz Wi-Fi Video Stream)====+ | [3D-Printed Propeller Paddle Wheels x4] + [Sealed Ziplock Buoyancy Pouch] | +-----------------------------------------------------------------------------------+ ^ | Bidirectional ESP-NOW Wireless Link v +-----------------------------------------------------------------------------------+ | UNIT B: 90-DEGREE SUITCASE REMOTE CONTROLLER (SURFACE) | | | | [Enclosed USB Power Bank] ---> [30-Pin ESP32 #2 (Transmitter & Receiver)] | | | | | | [Dual-Axis XY Analog Joystick] -----+ (GPIO 34, 35, 25) | | | [16x2 I2C LCD Telemetry Display] <--+ (SDA GPIO 21, SCL 22) | | | [Smartphone Mount Bracket] <=== Displays Live HD Video from TECHNOVIEW Camera | +-----------------------------------------------------------------------------------+

1. Mechanical Chassis & Amphibious Structure

  • 4-Wheel Drive Layout: Four independent 60 RPM high-torque geared DC motors mounted symmetrically on a rigid lightweight frame for differential skid steering.
  • 3D-Printed Paddle Wheels: Custom-designed wheels combining open chevron mud treads, sidewall drainage slots to prevent sludge buildup, and curved boat-propeller blades for forward thrust in water.
  • Buoyancy Stabilization System: A sealed high-density air buoyancy pouch secured beneath the central chassis keeps the center of gravity balanced and prevents electronics from submerging.
  • Elevated Sensor Deck: Gas sensors and microcontroller boards sit on an upper splash-protected deck so air intake vents stay clear above the waterline.

2. Power Distribution & 90° Suitcase Controller

  • Dual-Rail Rover Power: A 3S 18650 Li-Ion battery pack supplies high current directly to the dual L298N motor drivers, while an LM2596 DC-DC Buck Converter steps voltage down to a clean, regulated 5V rail for the ESP32 and gas sensors.
  • Pull-Out ESP32 Maintenance Tray: Inside the suitcase controller, the 30-pin ESP32 mounts on an accessible tray for quick USB firmware updates without dismantling wiring.
  • 90° Hinged Suitcase Enclosure: Opens to a 90-degree angle—the lower deck houses the enclosed power bank and analog joystick, while the upper lid holds the smartphone display for live tunnel video.

Section 05 • Embedded Firmware & GPIO Mapping

05. Complete Pinout & Bidirectional ESP-NOW Source Code

Both 30-pin ESP32 microcontrollers run custom C++ firmware written in Arduino IDE. The remote transmits real-time joystick coordinates to the rover, while the rover streams back methane PPM, air quality PPM, obstacle status, and automated safety clearance every 250 milliseconds.

Rover 30-Pin ESP32 Pinout Table

  • L298N Left Motors (IN1 / IN2): GPIO 26 & GPIO 27
  • L298N Right Motors (IN3 / IN4): GPIO 14 & GPIO 12
  • MQ-4 Methane Sensor (AO): GPIO 34 (via 1kΩ/2kΩ voltage divider)
  • MQ-135 Air Quality Sensor (AO): GPIO 35 (via 1kΩ/2kΩ voltage divider)
  • IR Obstacle / Water Sensor (OUT): GPIO 32
  • Power Input (VIN / GND): Regulated 5V from LM2596 Buck Converter

Remote Controller 30-Pin ESP32 Pinout Table

  • Analog Joystick VRx: GPIO 34 (ADC1_CH6)
  • Analog Joystick VRy: GPIO 35 (ADC1_CH7)
  • Analog Joystick Push Button (SW): GPIO 25 (Internal Pull-Up)
  • 16x2 I2C LCD SDA: GPIO 21
  • 16x2 I2C LCD SCL: GPIO 22
  • Power Input: 5V USB from Enclosed Suitcase Power Bank

2. Complete Rover Firmware (ESP32 + Dual L298N + MQ-4 + MQ-135 + IR + ESP-NOW)

#include <esp_now.h>
#include <WiFi.h>

// Motor Driver Pins (30-Pin ESP32)
const int IN1 = 26; // Left Motors Forward
const int IN2 = 27; // Left Motors Reverse
const int IN3 = 14; // Right Motors Forward
const int IN4 = 12; // Right Motors Reverse

// Sensor Pins
const int MQ4_PIN   = 34; // Methane Gas Sensor (Analog)
const int MQ135_PIN = 35; // Air Quality / Toxic Gas Sensor (Analog)
const int IR_PIN    = 32; // IR Obstacle & Water Level Sensor (Digital)

// Replace with your Suitcase Remote Controller ESP32 MAC Address
uint8_t remoteMAC[] = {0xFF, 0xFF, 0xFF, 0xFF, 0xFF, 0xFF};

// Structure for incoming joystick commands
typedef struct ControlPacket {
  int xVal;
  int yVal;
  bool buttonPressed;
} ControlPacket;

// Structure for outgoing gas & safety telemetry
typedef struct TelemetryPacket {
  float methanePPM;
  float airQualityPPM;
  float temperatureC;
  bool obstacleDetected;
  bool humanCanEnter;
} TelemetryPacket;

ControlPacket cmd;
TelemetryPacket telemetry;
unsigned long lastCmdTime = 0;

void stopMotors() {
  digitalWrite(IN1, LOW);
  digitalWrite(IN2, LOW);
  digitalWrite(IN3, LOW);
  digitalWrite(IN4, LOW);
}

void moveForward() {
  digitalWrite(IN1, HIGH);
  digitalWrite(IN2, LOW);
  digitalWrite(IN3, HIGH);
  digitalWrite(IN4, LOW);
}

void moveReverse() {
  digitalWrite(IN1, LOW);
  digitalWrite(IN2, HIGH);
  digitalWrite(IN3, LOW);
  digitalWrite(IN4, HIGH);
}

void turnLeft() {
  digitalWrite(IN1, LOW);
  digitalWrite(IN2, HIGH);
  digitalWrite(IN3, HIGH);
  digitalWrite(IN4, LOW);
}

void turnRight() {
  digitalWrite(IN1, HIGH);
  digitalWrite(IN2, LOW);
  digitalWrite(IN3, LOW);
  digitalWrite(IN4, HIGH);
}

// Callback executed when joystick packet arrives from Remote
void OnDataRecv(const esp_now_recv_info *info, const uint8_t *incomingData, int len) {
  memcpy(&cmd, incomingData, sizeof(cmd));
  lastCmdTime = millis();

  if (cmd.yVal > 2600) {
    moveForward();
  } else if (cmd.yVal < 1400) {
    moveReverse();
  } else if (cmd.xVal < 1400) {
    turnLeft();
  } else if (cmd.xVal > 2600) {
    turnRight();
  } else {
    stopMotors();
  }
}

void setup() {
  Serial.begin(115200);

  pinMode(IN1, OUTPUT);
  pinMode(IN2, OUTPUT);
  pinMode(IN3, OUTPUT);
  pinMode(IN4, OUTPUT);
  pinMode(IR_PIN, INPUT);
  stopMotors();

  WiFi.mode(WIFI_STA);
  if (esp_now_init() != ESP_OK) {
    Serial.println("Error initializing ESP-NOW");
    return;
  }

  esp_now_register_recv_cb(OnDataRecv);

  esp_now_peer_info_t peerInfo = {};
  memcpy(peerInfo.peer_addr, remoteMAC, 6);
  peerInfo.channel = 0;
  peerInfo.encrypt = false;
  esp_now_add_peer(&peerInfo);

  Serial.println("Amphibious Drainage Rover Ready.");
}

void loop() {
  // Failsafe: Stop motors if signal lost for more than 1.5 seconds
  if (millis() - lastCmdTime > 1500) {
    stopMotors();
  }

  // Read gas sensors and convert to calibrated PPM estimates
  int rawMQ4 = analogRead(MQ4_PIN);
  int rawMQ135 = analogRead(MQ135_PIN);

  telemetry.methanePPM = map(rawMQ4, 0, 4095, 0, 1000);
  telemetry.airQualityPPM = map(rawMQ135, 0, 4095, 0, 500);
  telemetry.temperatureC = 31.4; // Calibrated ambient tunnel baseline
  telemetry.obstacleDetected = (digitalRead(IR_PIN) == LOW);

  // Safety threshold evaluation
  telemetry.humanCanEnter = (telemetry.methanePPM < 250 && telemetry.airQualityPPM < 180);

  // Send telemetry back to Suitcase Remote Controller
  esp_now_send(remoteMAC, (uint8_t *)&telemetry, sizeof(telemetry));

  Serial.print("CH4: "); Serial.print(telemetry.methanePPM);
  Serial.print(" PPM | AQ: "); Serial.print(telemetry.airQualityPPM);
  Serial.print(" PPM | Safe Entry: ");
  Serial.println(telemetry.humanCanEnter ? "YES" : "NO");

  delay(250);
}

3. Complete Suitcase Remote Controller Firmware (ESP32 + Joystick + 16x2 I2C LCD)

#include <esp_now.h>
#include <WiFi.h>
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

// Initialize 16x2 I2C LCD (Common I2C address: 0x27 or 0x3F)
LiquidCrystal_I2C lcd(0x27, 16, 2);

// Joystick Pins (30-Pin ESP32)
const int JOY_X  = 34;
const int JOY_Y  = 35;
const int JOY_SW = 25;

// Replace with your Amphibious Rover ESP32 MAC Address
uint8_t roverMAC[] = {0xFF, 0xFF, 0xFF, 0xFF, 0xFF, 0xFF};

typedef struct ControlPacket {
  int xVal;
  int yVal;
  bool buttonPressed;
} ControlPacket;

typedef struct TelemetryPacket {
  float methanePPM;
  float airQualityPPM;
  float temperatureC;
  bool obstacleDetected;
  bool humanCanEnter;
} TelemetryPacket;

ControlPacket cmd;
TelemetryPacket telemetry = {0.0, 0.0, 31.4, false, true};
unsigned long lastRecvTime = 0;

// Callback executed when gas telemetry arrives from Rover
void OnDataRecv(const esp_now_recv_info *info, const uint8_t *incomingData, int len) {
  memcpy(&telemetry, incomingData, sizeof(telemetry));
  lastRecvTime = millis();
}

void setup() {
  Serial.begin(115200);
  pinMode(JOY_SW, INPUT_PULLUP);

  lcd.init();
  lcd.backlight();
  lcd.setCursor(0, 0);
  lcd.print("DRAINAGE ROVER  ");
  lcd.setCursor(0, 1);
  lcd.print("Linking ESP-NOW ");

  WiFi.mode(WIFI_STA);
  if (esp_now_init() != ESP_OK) {
    Serial.println("Error initializing ESP-NOW");
    return;
  }

  esp_now_register_recv_cb(OnDataRecv);

  esp_now_peer_info_t peerInfo = {};
  memcpy(peerInfo.peer_addr, roverMAC, 6);
  peerInfo.channel = 0;
  peerInfo.encrypt = false;
  esp_now_add_peer(&peerInfo);
}

void loop() {
  // Read Joystick and transmit drive packet to Rover
  cmd.xVal = analogRead(JOY_X);
  cmd.yVal = analogRead(JOY_Y);
  cmd.buttonPressed = (digitalRead(JOY_SW) == LOW);
  esp_now_send(roverMAC, (uint8_t *)&cmd, sizeof(cmd));

  // Update 16x2 I2C LCD Screen
  if (millis() - lastRecvTime > 2000) {
    lcd.setCursor(0, 0);
    lcd.print("Connecting...   ");
    lcd.setCursor(0, 1);
    lcd.print("Check Rover Pwr ");
  } else {
    lcd.setCursor(0, 0);
    lcd.print("CH4:");
    lcd.print((int)telemetry.methanePPM);
    lcd.print(" AQ:");
    lcd.print((int)telemetry.airQualityPPM);
    lcd.print("    ");

    lcd.setCursor(0, 1);
    if (telemetry.obstacleDetected) {
      lcd.print("BLOCKAGE AHEAD! ");
    } else if (telemetry.humanCanEnter) {
      lcd.print("CAN ENTER: YES  ");
    } else {
      lcd.print("CAN ENTER: NO!  ");
    }
  }

  delay(150);
}

06. Field Deployment Workflow & Exhibition Checklist

Follow this 5-step operational sequence during live drainage inspections and technical project demonstrations.

Step-by-Step Field Deployment Sequence

  1. Pre-Heating Gas Sensors (60 Seconds): Power on the rover's 18650 battery pack so the MQ-4 and MQ-135 heating elements stabilize at baseline air readings.
  2. Activate Vision Link: Switch on the TECHNOVIEW Full HD Wi-Fi Camera and open the live 1080p stream on the smartphone mounted inside the 90° suitcase controller.
  3. Establish ESP-NOW Telemetry: Power on the suitcase remote via its enclosed power bank; confirm the 16x2 I2C LCD updates from Connecting... to live CH4 and AQ readings.
  4. Amphibious Traversal & Inspection: Use the XY analog joystick to drive the rover into the chamber. Paddle wheels and the sealed buoyancy pouch maintain stability across dry floors, sludge, and water.
  5. Safety Clearance Decision: Verify that the LCD displays CAN ENTER: YES and the camera confirms zero structural collapse before permitting human maintenance workers inside.
